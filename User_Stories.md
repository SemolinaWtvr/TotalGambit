# User Stories

**By default**, users are redirected to the **Main Page** when accessing the application.

---

## Main Page

### Guest

* **As a Guest, I can sign up for a new account so that I can access the app’s features.**
* **As a Guest, I can log in to an existing account so that I can continue my progress.**
* **As a Guest, I can view the leaderboard so that I can see player rankings.**
* **As a Guest, I can search for a player in the leaderboard so that I can find specific users.**

---

### Player/Admin

* **As a Player/Admin, I can log off so that I can securely end my session.**
* **As a Player/Admin, I can view the leaderboard so that I can track rankings and competition.**
* **As a Player/Admin, I can search for players in the leaderboard so that I can find specific users.**
* **As a Player/Admin, I can access my profile page so that I can manage my personal information.**
* **As a Player/Admin, I can access all games so that I can play and earn tokens.**

---

### Admin (Only)

* **As an Admin, I can access the User Manager so that I can manage user accounts.**

---

## Profile Page

### Player

* **As a Player/Admin, I can change my username so that I can personalize my identity.**

  * Acceptance Criteria: username must be unique
  * Acceptance Criteria: maximum 24 characters
* **As a Player/Admin, I can edit my bio so that I can share information about myself.**

  * Acceptance Criteria: maximum 50 characters
* **As a Player/Admin, I can choose a profile picture from a predefined set or upload/capture my own photo so that my profile feels personal.**

---

### Admin

* **As an Admin, I can modify my token amount so that I can test or manage the system.**

  * Acceptance Criteria: value between 0 and 999,999

---

## Game 1: Blackjack

### Player/Admin

* **As a Player/Admin, I can play a game of Blackjack against a bot or another player so that I can practice or compete online.**
* **As a Player/Admin, I can place bets using tokens so that I can wager my balance.**
* **As a Player/Admin, I can forfeit a round so that I can exit a game early.**

---

## User Manager

### Admin

* **As an Admin, I can search for a player so that I can quickly locate accounts.**
* **As an Admin, I can rename a player so that I can correct or moderate usernames.**
* **As an Admin, I can reset a player’s profile picture so that I can enforce guidelines.**
* **As an Admin, I can delete a player’s bio so that I can remove inappropriate content.**
* **As an Admin, I can modify a player’s token amount so that I can manage balances.**
* **As an Admin, I can ban a player for a period of time so that I can enforce rules.**
